# SPI言語ノート — 赤ペン復習アプリ

自分のSPI言語分野の演習（手書きノートPDF）を書き起こして作った、ブラウザだけで動く復習用クイズアプリです。ビルド不要・サーバー不要、静的ファイルのみで動作します。

## 収録内容

- 全 **199問**（語彙・同義語 / 語句の用法 / 空所補充 / 空所補充(2箇所) / 二語の関係 / 文章整序 / 長文読解）
- 長文読解は本文つき、複数選択・記述抜き出しにも対応

## 遊び方

- **10問コース**：全ジャンルからランダムに10問
- **全問コース**：収録している全問をランダム順に
- **ジャンル別**：ジャンルを選んで10問 or 全問
- **苦手問題だけ**：直近で間違えた問題だけをまとめて解き直し（ブラウザのlocalStorageに保存、他の端末とは共有されません）

回答するとその場で正誤と正解がわかり、最後に結果と見直し画面が出ます。

## ローカルで試す

ファイルを開くだけでも動きますが、`fetch`系の制限を避けるため簡易サーバー推奨です。

```bash
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

## GitHub Pagesで公開する

1. このフォルダの中身（`index.html`, `style.css`, `app.js`, `data.js`）をリポジトリ直下に置いてpush
2. GitHubのリポジトリ → **Settings → Pages**
3. **Source** を `Deploy from a branch`、ブランチを `main`（フォルダは `/root`）に設定して保存
4. 数分後、`https://ユーザー名.github.io/リポジトリ名/` で公開されます

## 問題を追加・編集したい場合

`data.js` の `QUESTIONS` 配列を直接編集してください。1問は次の形です。

```js
{
  "id": 1,
  "genre": "vocab",              // vocab / usage / blank / blank2 / relation / order / reading
  "passage": null,                // 長文読解の場合は本文の文字列
  "instruction": "...",          // 問題文の上に出る指示文（グレーの帯）
  "prompt": "...",               // 設問本文（下線部や空所など）
  "type": "single",              // single / multi / text
  "choices": ["...", "...", ...],
  "answer": 0                     // single: index number / multi: [index,...] / text: 正解の文字列
}
```

`app.js` はこの配列の中身をそのまま参照するので、問題を増やしてもコード側の変更は不要です。

## ファイル構成

```
index.html   画面のマークアップ
style.css    見た目（赤ペン先生ノート風）
app.js       画面遷移・採点・履歴管理のロジック
data.js      全問題データ
```

## プライバシー

演習の記録（正誤履歴）はブラウザの localStorage のみに保存され、外部には一切送信されません。ホーム画面の「記録をリセット」でいつでも消去できます。
